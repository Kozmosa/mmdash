# MCP Gateway

Remote MCP boundary built on the official MCP SDK 2.x. It supports modern
Streamable HTTP, CLI and Agent bearer tokens, principal-bound mmdash sessions,
project/tool authorization, safe errors, audit events, and modular tools.

See [the development guide](../../docs/development/mcp-gateway.md) and
[searchable tool catalog](../../docs/api/mcp-tools.md).
